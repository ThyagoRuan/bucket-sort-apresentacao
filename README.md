# Bucket Sort – Apresentação

Requisito: Node.js 18 ou superior.

    npm install
    npm run dev

Abre em http://localhost:5173. Use as setas ← → para trocar de slide.

Para rodar a versão final (mais leve) durante a apresentação:

    npm run build
    npm run preview

Abre em http://localhost:4173. Depois do `npm install` tudo funciona offline.
