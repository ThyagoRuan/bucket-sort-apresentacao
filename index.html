Bucket Sort

Ordenação por distribuição em “baldes”

Apresentação sobre algoritmos de ordenação · TypeScript

Use as setas ← → ou os botões abaixo para navegar.

Ideia base

  1. Distribuir: cada elemento vai para um balde conforme a sua faixa de valores.
  2. Ordenar: cada balde é ordenado separadamente (geralmente com Insertion Sort).
  3. Concatenar: os baldes, já em ordem, são juntados em um único vetor.

É um algoritmo não comparativo na etapa de distribuição: o balde é calculado por uma fórmula, sem comparar elementos entre si.

Funciona melhor quando os dados estão distribuídos de forma uniforme no intervalo.

Código em TypeScript

function bucketSort(arr: number[], bucketCount = 5): number[] {
  if (arr.length <= 1) return [...arr];

  const min = Math.min(...arr);
  const max = Math.max(...arr);
  const range = (max - min + 1) / bucketCount;   // tamanho da faixa

  // 1. Distribuir
  const buckets: number[][] = Array.from({ length: bucketCount }, () => []);
  for (const value of arr) {
    const i = Math.floor((value - min) / range);
    buckets[i].push(value);
  }

  // 2. Ordenar cada balde e 3. Concatenar
  return buckets.flatMap(insertionSort);
}

function insertionSort(bucket: number[]): number[] {
  const a = [...bucket];
  for (let i = 1; i < a.length; i++) {
    const key = a[i];
    let j = i - 1;
    while (j >= 0 && a[j] > key) { a[j + 1] = a[j]; j--; }
    a[j + 1] = key;
  }
  return a;
}

console.log(bucketSort([29, 25, 3, 49, 9, 37, 21, 43]));
// [3, 9, 21, 25, 29, 37, 43, 49]
  • range define a largura de cada faixa; (value - min) / range dá o índice do balde.
  • O + 1 garante que o maior valor não caia fora do último balde.

Vantagens

  • Muito rápido em dados uniformes
  • Fácil de entender e implementar
  • Pode ser estável

Limitações

  • Pior caso quadrático
  • Usa memória extra
  • Depende da escolha do número de baldes

Use quando os valores estiverem bem espalhados em um intervalo conhecido, como números reais entre 0 e 1.
